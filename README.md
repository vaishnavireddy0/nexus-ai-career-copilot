# NEXUS AI — Career Copilot

An AI-powered career assistant built using Python, Flask, and Google Gemini.

## Features

- AI-powered resume analysis
- Resume and job-description matching estimates
- ATS keyword suggestions
- Interview questions and sample answers
- Role-specific interview preparation

## Technology Stack

- Python
- Flask
- Google Gemini API
- HTML and CSS
- Gunicorn

## Run Locally

1. Create a Python virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Create a `.env` file containing your private `GEMINI_API_KEY`.
4. Run `python app.py`.
5. Open http://127.0.0.1:5000.

## Security

Never upload `.env` or expose your API key publicly.

## Limitations

AI-generated feedback and job-match scores are estimates, not guarantees.
